# Student Grade Checker

## Description

This project is a simple Python program.
It is a student grade checker that calculates the average grade of a student.

The program determines if the student passed or failed.

## How it works

1. The program defines a function called `calculate_average`.
2. The function calculates the average grade of a list.
3. Another function called `check_status` evaluates the result.
4. The program checks if the average grade is greater than or equal to 3.0.
5. The program prints the student's information and result.
