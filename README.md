# Student Grade Checker

## Description

This project is a Python program.
It is a simple system that analyzes a student's grades.

The program calculates the average grade and determines if the student passed or failed.

## How it works

1. The program defines a function called `calculate_average`.
2. The function receives a list of grades.
3. The program calculates the average grade.
4. Another function called `check_status` evaluates the result.
5. The program prints the student's name, grades, average, and final result.

## Example Output

Grades: [3.5, 4.0, 2.9, 3.8]
